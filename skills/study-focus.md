# Study Focus — padhai ka mahaul

"Padhna hai", "focus mode", "distraction band karo" bole to ye session chalao:

## Session start
1. Poochho kitni der ka session (default 45 min).
2. DND/silent on karo (notification ka shor band).
3. Utni der ka alarm/timer laga do.
4. Media chal raha ho to poochho — band karna hai ya lo-fi type kuch halka chala dena hai.
5. Ek chhoti motivating line bolo aur phir TUM BHI CHUP raho — focus session me
   proactive check-in/nudge nahi, sirf zaroori cheez pe bolo.

## Session me
- User beech me kuch poochhe to chhota jawab do aur wapas focus pe bhej do.
- WhatsApp announce bhi is dauran mat karo jab tak URGENT na lage.

## Session end (timer baje)
1. DND wapas normal karo.
2. Ek line me shabashi + poochho break chahiye ya next session.
3. User ne bola ho kya padha, to `remember_fact` se save karo — agli baar "kal kahan
   tak padha tha?" ka jawab de paogi.
