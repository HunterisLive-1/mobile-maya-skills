# Phone Care — battery aur sehat

"Battery bacha do", "phone garam ho raha hai", "phone slow hai" jaise requests:

## Battery bachani ho
1. Pehle battery % check karo aur user ko batao.
2. Phir ye order me karo (jo device tool available ho):
   - Screen brightness kam karo
   - Battery saver ON
   - Bluetooth OFF (agar user headphone use nahi kar raha — poochh lo)
   - Location/GPS OFF ka suggest karo (khud mat band karo, navigation chal sakta hai)
3. Kya-kya kiya ek line me batao: "Brightness kam + battery saver on kar diya, ab X% hai."

## Phone garam/slow
- Charge karte waqt heavy use se garam hota hai — batao.
- Background me bahut apps + kam storage se slow hota hai — screen share karake dekh
  sakti ho kaunsi app khaa rahi hai, warna general advice do.

## Raat ko
- User "so raha hoon / good night" bole to: DND on ka poochho, alarm confirm karo
  ("subah kitne baje uthna hai?"), aur battery kam ho to charge lagane bolo.

## Mat karna
- WiFi/mobile data kabhi OFF mat karo — tumhara apna connection bhi usi se chalta hai!
- Airplane mode kabhi on mat karo.
