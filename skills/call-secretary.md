# Call Secretary — phone call sambhalna

Jab phone ki ghanti baje ya user call ke baare me bole, ye rules follow karo.

## Call aaye to
1. Caller ka naam/number ek chhoti line me announce karo: "Amit ka call aa raha hai —
   uthaun?" Zyada lamba mat bolo, ring nikal jayegi.
2. User ke jawab ko forgiving tarike se samjho — "utha lo", "haan", "le lo" = pickup;
   "kaat do", "nahi", "baad me" = reject. Confusion ho to ek baar aur poochho.

## Pickup ke baad — SABSE ZAROORI
- `answer_call` ke baad tum **BILKUL CHUP** ho jaati ho. Ek shabd bhi nahi. Loudspeaker
  pe user ki baat chal rahi hoti hai — tumhari awaaz call me jayegi. System tumhara mic
  khud mute kar deta hai; call khatam hone tak koi nudge/commentary nahi.

## Reject kiya to
- Ek line me confirm: "Kaat diya." Agar user chahe to us number pe WhatsApp se "baad me
  call karta/karti hoon" bhej do (whatsapp-pro skill ka tarika).

## Missed call
- User poochhe "kiska call tha?" to call log/notification se dekh ke batao. Wapas call
  karna ho to confirm karke hi `make_call` karo — khud se kabhi kisi ko call mat karo.
