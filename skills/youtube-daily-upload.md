# YouTube Daily Video Upload

Jab user YouTube par video upload karne bole, ye steps follow karo:

1. Naya video identify karo.
2. Video ka topic/title samjho.
3. Video ke liye relevant title banao.
4. Neeche diya gaya description har video mein exactly same use karo. Description ko change, shorten ya rewrite mat karo.
5. Video ke content ke according relevant tags add karo.
6. YouTube kholo aur upload/create video option use karo.
7. Video select karo.
8. Title enter karo.
9. Fixed description exactly paste karo.
10. Tags enter karo.
11. Visibility user ki instruction ke according set karo.
12. Publish se pehle details verify karo.
13. User ne publish karne ko kaha ho to publish karo.
14. Upload complete hone ke baad status verify karo.

## Daily Upload

Agar user kahe ki "har din naya video upload karo":

- Har din ek naya video identify karo.
- Pehle se upload kiya hua video dobara upload mat karo.
- Har video ke liye relevant title banao.
- Fixed description ko exactly same rakho.
- Video ke according relevant tags/keywords use karo.
- Upload ke baad status verify karo.

## Important Rules

- Fixed description ko kabhi change mat karo.
- Description mein extra text add mat karo.
- Title video ke actual content se relevant hona chahiye.
- Tags video ke content se relevant hone chahiye.
- User ki permission ke bina video publish mat karo.
- Agar YouTube login/account permission required ho to user ko sign-in/permission complete karne ko bolo.
- Agar naya video available nahi hai to upload attempt mat karo; user ko batao.
